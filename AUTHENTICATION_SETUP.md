# Система Аутентификации и Регистрации

## ✅ Реализованные функции

Полная система регистрации и входа для новых пользователей с полями:
- **Логин** (username) - уникальный идентификатор
- **Email** - электронная почта (валидация включена)
- **Пароль** - минимум 8 символов
- **Имя и Фамилия** - личные данные пользователя

## 📱 Главная страница (HomePage)

Новая красивая главная страница доступна на маршруте `/` с:
- Профессиональным дизайном с градиентом (фиолетовый)
- Двумя табами: "Вход" и "Регистрация"
- Адаптивностью для всех размеров экранов
- Описанием функций приложения

### Форма Входа
- Поле: Имя пользователя
- Поле: Пароль
- Кнопка входа с состоянием загрузки

### Форма Регистрации
- Поле: Имя пользователя (логин)
- Поле: Email
- Поле: Имя
- Поле: Фамилия  
- Поле: Пароль
- Поле: Подтверждение пароля
- Валидация на совпадение пароля
- Сообщения об ошибках

## 🔐 Backend API

### Endpoints аутентификации
```
POST /api/v1/auth/register/ - Регистрация нового пользователя
POST /api/v1/auth/login/    - Вход в аккаунт
POST /api/v1/auth/logout/   - Выход из аккаунта
GET  /api/v1/users/me/      - Получить информацию текущего пользователя
```

### Безопасность
- Token-based authentication (DRF Token)
- Валидация пароля (минимум 8 символов)
- Хеширование паролей
- CORS настройки для фронтенда

## 🚀 Как использовать

### Регистрация новых пользователей
1. Перейдите на главную страницу (`/`)
2. Нажмите на таб "Регистрация"
3. Заполните все поля формы
4. Нажмите "Создать аккаунт"
5. Автоматический редирект в личный кабинет

### Вход существующих пользователей
1. На главной странице (`/`)
2. Останется в табе "Вход" (или перейдите туда)
3. Введите логин и пароль
4. Нажмите "Войти"
5. Редирект в задачи

## ✨ Особенности дизайна

- **Адаптивный дизайн** - работает на мобильных, планшетах и десктопах
- **Плавные переходы** - анимации при переключении табов
- **Обратная связь** - сообщения об ошибках и успехе
- **Современный UI** - градиенты, тени, закругленные углы

## 🔧 Валидация

### На фронтенде (React)
- Проверка заполнения всех полей
- Проверка совпадения пароля и подтверждения
- Минимальная длина пароля (8 символов)

### На бэкенде (Django)
- Уникальность username
- Уникальность email
- Валидация email формата
- Минимальная длина пароля (8 символов)
- Проверка пароля на сложность
